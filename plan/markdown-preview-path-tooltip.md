# Markdownプレビューのファイルパスツールチップ

## 対象

- Issue #226

## 調査結果

Markdownプレビューのヘッダーは`fileURL.lastPathComponent`だけを表示しており、同名ファイルを区別できない。SwiftUIの`help`はmacOSの標準ツールチップとして既存のボタンにも使われているため、ヘッダーのファイル名へフルパスを渡せば表示を変えずに詳細を確認できる。

## 方針

- ヘッダーのファイル名表示は現状の省略・中央寄せを維持する。
- ホバー時のツールチップに`fileURL.path`を表示する。
- ファイル未選択時は空のツールチップとし、既存のプレースホルダー表示を維持する。
- 実機でのホバー確認はリリース後に行うため、CI通過後にマージする。

## 実装内容

- Markdownプレビューのファイル名Textへフルパスの`help`を追加。

## テスト・検証

- `just lint`とCIの`just test-fast`を実行する。
- 実機でファイル名ホバー時にフルパスが表示されることを確認する（リリース後）。

## 対象外

- ヘッダーのレイアウト変更。
- 履歴一覧の表示内容変更。
- #224の履歴UI変更。
