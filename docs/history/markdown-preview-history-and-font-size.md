# Markdownプレビューの履歴保持とフォントサイズ設定

## 対象

- Issue #246: Markdownプレビューのフォントサイズを個別に管理する
- Issue #247: 履歴を遡っても後続項目を保持する

## 調査結果

- Markdownプレビューのフォントサイズは、フォーカス中のターミナルセル高から算出している。ターミナル側のサイズ変更にプレビューも追従するため、独立した調整値がない。
- 履歴モデルは戻る・進むの位置を配列の添字で管理し、`open(url:)`で新しいファイルを開いた場合だけ進む側の履歴を削除する。戻る操作自体は削除しない。
- 履歴一覧と選択位置は配列から算出しており、SwiftUIのObservableObjectが直接監視する公開状態ではない。履歴状態を明示的に公開し、戻る操作後も全項目を保つ回帰テストを追加する。

## 方針

- フォントサイズ設定はMarkdownプレビュー用に独立させ、UserDefaultsへ保存する。
- 初期状態では従来どおりターミナルのセル高に追従する。
- プレビューのヘッダーからサイズを調整し、いつでもターミナル追従へ戻せるようにする。
- 履歴一覧と現在位置を`@Published`状態にし、戻る・進む・任意項目の選択に合わせて更新する。
- 戻るだけでは後続項目を削除しない。別のファイルを新しく開いた場合は、既存のブラウザ型ナビゲーションどおり後続項目を削除する。

## テスト・検証

- モデルテストで戻る操作後も後続履歴と現在位置が保たれることを確認する。
- モデルテストでプレビュー用フォントサイズの初期追従値、個別値、追従へのリセットを確認する。
- `just lint`と関連するmacOSテストを実行する。
- UI上でヘッダーからサイズ変更と追従リセットを確認する。

## 実装記録

- Markdownプレビューのヘッダーにフォントサイズ調整ポップオーバーを追加。10〜32 ptで設定し、UserDefaultsへ保存する。
- `Match Terminal`で専用設定を解除すると、従来のターミナルセル高連動（0.8倍）へ戻る。セル高がない場合はシステム標準サイズを使う。
- 履歴項目と現在位置を`@Published`状態として公開し、戻る操作後に後続履歴が保持されるモデルテストを追加。
- フォントサイズ解決の既定値・個別設定・範囲制限をテストする。
- `just lint`は成功。`just test`はXcode XCTestを含め成功。
- ヘッダー操作の実機での見た目確認はPRのhands-on verificationに残す。
