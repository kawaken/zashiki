# Markdownプレビュー履歴を新しい順に表示

## 対象

- Issue #252

## 調査結果

- `MarkdownPreviewModel`は履歴を開いた順に保持し、各項目のIDに履歴内の位置を使っている。
- 履歴ポップオーバーも配列の順番で表示しているため、古い項目が上、新しい項目が下に並ぶ。
- 選択状態とナビゲーションは履歴IDに依存するため、保存順を並べ替えるのではなく表示用配列だけを逆順にする。

## 方針

- 履歴の保存順と戻る・進むの挙動は変更しない。
- 履歴UIだけ最新の項目から表示する。
- 行のIDは元の履歴インデックスを維持し、選択位置と任意項目への移動を保つ。

## テスト・検証

- 新しい順の表示用項目と元のインデックスが保たれることをモデルテストで確認する。
- `just lint`と`just test`を実行する。

## 実装記録

- 履歴モデルに最新順の表示用配列を追加し、ポップオーバーはその順で描画する。
- 各項目のIDは元の履歴位置のままなので、選択中の表示と履歴移動は従来どおり。
- 最新順のURLとID、現在位置を検証するモデルテストを追加。
- `just lint`とmacOS XCTestを含む`just test`は成功。
